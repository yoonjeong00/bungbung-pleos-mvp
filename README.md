# 붕붕이 · WHITE HMI MVP

차량 관리 캐릭터 토토를 위한 가로형 작동 프로토타입. `dist/index.html`과 `dist/js/hmi-app.js`가 현재 진입점입니다. 과거 mint/pixel 파일은 비교/이관용으로 남아 있으며 새 페이지에서 로드하지 않습니다.

## 화면
주차 홈, 성장 기록, 배지 도감, 꾸미기, 주유 회복, 하루 마무리, 주행 화면. 화이트·실버 표면, 코발트 선택 상태, 검은 선 아이콘과 3D 스타일 토토를 사용합니다. 주행/주차 레이아웃은 각각 27:36:37과17.5:82.5입니다. 이는 첨부 콘셉트 시안을 재구성한 비율이며 Pleos 공식 인증 규격을 의미하지 않습니다.

## 시연
상단 시연 패널에서 화면 바로 보기 또는 S1–S10을 선택합니다. S1–S5 자동 재생, 일시정지, 이어 재생, 다음 단계가 있습니다. 시나리오의 다음 장면 이동은 현재 연출 확인으로 처리합니다. 일반 차량 상태 전환에서는 이벤트를 보존합니다. 기어 P에서만 상호작용하며, 제한 신호 미수신/오류에는 화면을 제한합니다. 숫자/기어/기온은 수동 패널에서도 변경할 수 있습니다.

회복 시49→620km와 배지/밥그릇이 적립됩니다. 단계 임계값은300/2000/6000km입니다. 저장은 브라우저 localStorage만 사용합니다. 소품은 선택·미리보기·적용·저장을 지원합니다. 의상/방은 기본 항목 소개만 제공합니다.

## 그래픽과 한계
`hmi-assets/reference-*.png`는 제공된 시안 이미지입니다. `hmi-art.js`가 필요한 그림 부분을 SVG viewport로 재사용합니다. UI 문구, 숫자, 선택 상태, 진행률은 HTML로 렌더링합니다. `home-room.png`는 3D 스타일로 새로 생성한 방 장면입니다. 이는 2D 렌더 이미지이며 실제 리깅된3D 모델이 아닙니다. 방 장면은 고정 이미지여서 저장 소품은 별도 적용 상태로 표시합니다. 지도·차량·기후 바는 시연용이며 실제 길안내/차량 제어/SDK 연동은 없습니다.

## Android
`python scripts/sync-android.py`로 웹 자산을 Android WebView 프로젝트에 동기화합니다. Android SDK/에뮬레이터가 준비된 환경에서 기존 android 프로젝트를 빌드하세요. 이 환경에서는 APK 빌드나 에뮬레이터 실행을 검증하지 않았습니다.

## 검증
`node tests/event-lifecycle.mjs`, `node tests/team1.mjs`, `node tests/state-regressions.mjs`, `node tests/logic.mjs`, `node tests/layout-model.mjs`.
브라우저에서7개화면, S1→S4, S5 성장, 회복의 재로드 복원과 확인 동작을 확인했습니다.


## 팀 협업
- 팀원 1: 가상 차량 공급기·시나리오·조작 패널, 주차 중 반응과 연출.
- 팀원 2: 성장·게이지·배지·저장 규칙, 통합·검증.
- 팀원 3: 정적 화면·반응형·캐릭터 에셋, 시연 영상.
- 각자 `feat/담당-기능` 브랜치에서 작업하고 Pull Request로 main에 합칩니다.
- 초대: 저장소 Settings → Collaborators → Add people. 초대 수락 후 clone합니다.

## 로컬 실행
```bash
python3 -m http.server 8080 --directory dist
```
브라우저에서 http://localhost:8080 을 엽니다.
Android Studio에서 android 폴더를 열기 전에 `python3 scripts/sync-android.py`를 실행하세요.
Android SDK 및 JDK 등 빌드 환경은 별도로 필요합니다. 실제 APK·Pleos 에뮬레이터 실행은 아직 검증되지 않았습니다.

## 현재 알려진 미해결 사항
이 저장소는 기존 MVP의 이관본이며 아래 문제를 해결한 릴리스가 아닙니다.
- 시연 fixture가 저장 상태를 덮어쓸 수 있음.
- 일부 배지·성장·회복 조건과 주차 시점의 확정 및 중복 억제 보완 필요.
- 방 캐릭터 그림에 성장·복장·기분이 완전히 반영되지 않음.
- 새 HMI에 걷기·메모 끌기 등 연출 연결 미완료.
- 시동 OFF 하루 요약, 저온 복장, 신호 대기 속도 표현 보완 필요.
- Android embedded 쿼리 분기와 다운로드 링크 보완 필요.
- 저장소 접근 실패 처리, 작은 창 크기 대응, 새 HMI 통합 테스트 부족.
- 지도·속도·공조 표시와 차량 데이터는 모의 시연이며 실제 SDK 연동 없음.

기존 배포용 설정·다운로드 ZIP·Android 중복 생성 자산은 이관에서 제외했습니다.
