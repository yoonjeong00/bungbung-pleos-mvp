# 토토 Android 주차 모션 검증판

- 디버그 APK 전용. 기본 실행, 시연·녹화, 출시 빌드의 모션은 바꾸지 않는다.
- 합의된 고정 배경, 토토 좌우 흔들림과 눈 감은 미소, 터치 하트와 짧은 끄덕임을 재사용한다. 손 인사 없음.
- 실제 신호 출처로 받은 P + 주행 제한 해제 값이 둘 다 최신인 내 방에서만 허용한다. D/R/N, 주행 제한, 신호 만료·오류, 화면 이탈·백그라운드 및 동작 줄이기에서는 정지한다.
- 시동은 아직 확인용이고 차량 경고 실수신은 미검증이다. 이 디버그 검증판은 출시 안전 판정을 대신하지 않는다.
- Pleos에서 디버그 APK를 설치하고 앱을 종료한 뒤 `adb shell am start -n com.hipnote.bungbung/.MainActivity --ez qa_parked_motion true`로 다시 시작한다. 일반 실행은 옵션 제외.
- `node --test tests/*.mjs`로 안전 조건과 기존 기능을 함께 검증한다. 실차와 마켓은 이 브랜치 범위가 아니다.
