# 제출 전 데이터·SDK 점검

검토 대상: `feat/team1-demo-session` 작업본. 코드와 Node 실행 검증이며 실제 Pleos 하드웨어 수용 테스트가 아니다.

## 수정

- 신규 저장 상태에 `onboardingComplete:false`를 명시했다. 기존 정상 저장본은 완료 상태로 마이그레이션해 토토를 초기화하지 않는다. 첫 만남 화면 연결은 사용자 흐름 담당이 수정했다.
- SDK 알림 수신 횟수와 **실제 숫자 변경 횟수**를 분리해 표시한다. 네이티브 `valueChanges`가 없으면 0으로 위장하지 않고 확인 전으로 표시한다. 같은 0 km 알림을 49회 받은 것은 값 변경 검증을 뜻하지 않는다.
- `live` 패킷이라도 숫자가 null/음수/NaN이거나 연결·지원 상태가 부적합하면 오류 상태로 표시하고 숫자를 숨긴다.
- 45초 이상 오래되거나 미래 시각이 부적절한 값은 현재 거리처럼 표시하지 않는다.
- S6 설명을 실제 기능에 맞게 `외기온 -3°C 모의 입력 · 자동 착용 준비 중`으로 정정했다.
- 최종 기획서와 일치하도록 2,000 km 단계 명칭을 `청년`으로 통일했다.

## 구현 범위와 제출 표현

- SDK 실수신은 독립 누적 거리 모니터에만 연결되어 있다. 토토 성장 거리·기어·연료·온도·주행 제한은 모의 공급기를 사용한다.
- 주유 회복은 모의 주행 가능 거리 증가를 이용한 추정이다. 실제 주유 감지·오탐 검증·주유소/내비 연동은 없다.
- 실제 CarUxRestrictions, 차량 경고 우선 처리, 경고 중 성장 거리 별도 적립은 없다.
- 시동 OFF에 자동 연결된 하루 마무리가 없다. S10은 명시적으로 실행하는 모의 요약이다.
- 저온 목도리/고온 선글라스 자동 착용, 와이퍼·라이트 실제 연동은 없다.
- 성장 기록은 단계 안내이며 날짜별 성장 이력 앨범이 아니다.
- 배지 first/meal/grow/cold만 조건 로직이 있다. time/mileage는 아직 조건 구현이 없다.
- 최초 실제 차량 ODO 기준 설정·차량별 저장 분리·실차 재조회는 미구현이다. 현재 기본 ODO 10,000 km는 모의 기준이다.
- 자동 재생은 S1~S5 핵심 투어다. S6~S10은 개별 시나리오/ADB 투어로 확인한다.

**판단:** 모의 핵심 시연 + 실제 SDK 누적 거리 모니터를 명확하게 구분하는 조건으로 시연할 수 있다. 실제 차량 상태와 연동된 완성 앱이라고 제출해서는 안 된다. SDK 숫자 변경과 최종 APK 화면 조작은 기기에서 별도 확인해야 한다.
