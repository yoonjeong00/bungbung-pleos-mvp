# Pleos 주행 가능 거리 실수신 검증

- Java 변경은 #16 → #17 → #18 순으로 검토한다. 이 웹 변경은 #20 이후 main에서 그 Java 스택과 함께 검증하는 용도다.
- 주행 가능 거리는 수신 표시 전용이다. 49 / 150 / 0 km 같은 유효값은 표시하고 권한 없음·미지원·오류·15초 초과 미수신에서는 대시를 표시한다. 실제 거리 변화로 주유 이벤트·보상이나 토토 반응을 일으키지 않는다. 기존 모의 주유와 성장 기준은 유지한다.
- Pleos에서 정상 권한 흐름을 거친 검증용 APK를 열고, 공식 Virtual Console의 Remaining Range를 49000 → 150000 → 0 m로 설정한다. 각 입력 후 갱신이 끝난 화면의 홈 카드와 상단 SDK 표시를 캡처한다.
- 권한이 없는 테스트 상태에서는 0km가 아니라 대시가 나오는지 확인한다. 테스트 종료 후 에뮬레이터 값을 원상 복구한다.
- 이 PR의 자동 검증은 Java와 웹 사이의 패킷·표시 계약에 대한 테스트다. 새 통합 APK와 Pleos 화면 검증은 별도다.
