# 제출 전 사용자 흐름 점검

검증 대상: `feat/team1-demo-session`, SDK/출발 이미지 반영 후 작업 스냅샷.
검증 방식: 실제 `hmi-app.js` 모듈을 minimal DOM adapter에서 실행해 입력·버튼 handler·생성 HTML·저장값을 확인. 이는 브라우저 렌더링/Android 터치 검증이 아니다.

## 수정

- P1 신규 사용자가 첫 만남 없이 내 방으로 진입: `onboardingComplete`와 birth enqueue 연결. 데이터 담당의 load migration과 통합. 기존 저장 사용자에게 강제로 온보딩을 다시 띄우지 않는다.
- 이름 변경에 취소 동선 추가, 저장 버튼과 신규 시작 구분. 12자 제한 안내/입력 제한 일치, 공백은 토토, 한글 받침 조사 처리.
- 빠르게 누른 이전 화면의 detached 확인 버튼은 다음 이벤트를 확인하지 않도록 차단.
- 의상·방 탭은 실제 변경 기능이 없어 ‘준비 중’ 표시하고 적용 버튼 제거.
- 잠긴 소품 저장 버튼 비활성화. 소품은 선택 상태만 저장되며 착용 합성 미구현임을 표시.
- 홈 대표 이미지가 실시간 성장·소품 상태를 반영한다고 오인하지 않도록 안내.
- 미구현 시간/누적 거리 배지는 준비 중 표시.
- SDK가 실제 수신 중이어도 앱 상단이 ‘차량 SDK 미연결’이라고 표시하던 모순 제거. 앱 모의 데이터와 SDK 거리 별도 표시 문구 사용.
- 저온 장면은 홈에서 추위 안내를 표시. 자동 목도리 착용을 구현했다고 주장하지 않는다.
- 출발 화면 주행 가능 거리 km 단위 추가.
- 온보딩 중첩 SVG screenshot crop을 독립 WebP img로 교체(실제 이미지 추출은 화면 담당).

## 실제 handler 감사

| 조작 | 연결된 동작 | 결과/한계 |
|---|---|---|
| 첫 만남 시작 | 이름 정규화, onboardingComplete, birth 완료, home | 테스트 통과, Android 키보드는 미검증 |
| 이름 바꾸기 | 이름 화면 열기 → 저장/취소 | 저장 지속, 취소 원래 이름 유지 |
| 토토 터치 | joy 말풍선 1.6초 | P 이탈/화면 숨김 취소, 독립 캐릭터 모션 아님 |
| 내 방/성장 기록/꾸미기 | page 변경, 소품 pending 재설정 | handler 연결 확인 |
| 성장 카드 | 단계/해금 거리 toast | 소개 카드이며 날짜별 성장 앨범 아님 |
| 배지 카드 | 배지 상세/획득 여부 | time·mileage 준비 중 |
| 주행 가능 거리 | range 상세 | 모의 거리/미지원 상태 구분, 내비 연결 없음 |
| 오늘의 주행 | summary 미리보기 | 확인/내 방으로 복귀 |
| 옷장 열기 | 소품 탭 진입 | 미리보기 선택, 취소, 선택 저장 |
| 잠긴 소품 | 미리보기만 | 저장 disabled, 해금 조건 전체 미구현 |
| 의상/방 | 준비 중 화면 | 기본 시안 설명, 적용 버튼 없음 |
| 이벤트 확인/뒤로 | preview 종료 또는 active event 완료 | 같은 이벤트 반복 없음, 주차에서만 가능 |
| 시연 패널/설정 | 패널 토글 | 개발자 시연 조작, 실제 차량 제어 아님 |
| S1–S5 재생/정지/다음 | ScenarioPlayer | S6–S10은 개별 선택/ADB 투어 |
| 시연 초기화 | fixture home, 저장 보존 | 신규 사용자 데이터 삭제 아님 |
| 내 토토로 돌아가기 | session.leave, 저장 사용자 복원 | 시나리오 이름/보상 저장 오염 없음 |
| 차량 데이터 적용 | mock provider patch | 입력 유효성 처리, SDK setter 아님 |
| 전체 화면 | 브라우저 fullscreen API | Android에서는 외부 프레임 숨김 |

## 남은 실제 환경 검증

Android 키보드와 입력창 가림, 손가락 연속 클릭 타이밍, 화면 크기별 겹침, SDK 값 실제 변경, 앱 중지·복귀, GPU 잔상은 이 테스트로 통과 판정하지 않는다. 제출 APK에 대해서 사용자 환경에서 재현해야 한다.

## 미구현/시연 한계

- 토토 성장·기어·연료·온도는 모의 데이터, SDK 누적 거리와 분리.
- 방 이미지의 토토 외형은 고정 대표 이미지, 선택 소품의 실제 착용 합성 없음.
- 독립 캐릭터 걷기/호흡/먹기/인사 모션 없음.
- 방/의상 변경, 시간·누적 거리 배지, 날짜별 성장 앨범 없음.
- 자동 목도리/선글라스 착용, 실제 시동 OFF 요약, NaviHelper 주유소 안내 없음.
- 실제 CarUxRestrictions 기반 제한은 별도이며 모의 제한 동작을 안전 인증으로 간주하지 않는다.
