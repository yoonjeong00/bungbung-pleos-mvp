# 마이카펫 — 제출 영상 촬영 순서

## 촬영 준비
1. main 최신 코드를 가져오고 `python3 -m http.server 8080 --directory dist` 서버를 켭니다.
2. `http://localhost:8080/?android=1&record=1&v=20261125-r1`를 크롬에서 엽니다.
3. 브라우저 확대율 100%에서 시작하고 F 또는 상단 ‘전체 화면’을 누릅니다. 전체 문서를 표시하므로 모의 데이터 안내는 유지됩니다. F로 해제할 수 있습니다.
4. 1을 눌러 신규 시연을 시작합니다. 개인 저장값은 삭제되지 않습니다. 입력칸에 커서가 있으면 단축키를 받지 않으므로 빈 제목 영역을 클릭한 후 누릅니다.
5. 첫 장면의 귀·제목·시작 버튼과 화면 하단이 모두 보이는지 짧은 시험 녹화로 확인합니다. 최종 녹화는 앱 콘텐츠와 모의 데이터 안내가 함께 보이도록 합니다.

## 약 3분 본편
| 순서 | 조작 | 화면에서 확인할 결과 | 설명할 가치 |
|---|---|---|---|
| 1, 20초 | 1 → 이름 ‘토토’ 확인 → ‘토토와 함께 시작하기’ 클릭 | 첫 만남에서 내 방으로 이동 | 나와 함께 달리며 자라는 차량 동행 친구, 마이카펫 |
| 2, 20초 | 방의 토토 클릭 → 말풍선 확인 → 성장 기록 → 내 방 | 터치 반응·성장 기록·탭 이동 | 주차 중에만 교감하고 기록을 살펴봅니다 |
| 3, 15초 | 2 | 안전벨트 토토, ‘오늘도 함께 달려요’, 꾸미기 탭 없음 | 모의 D 신호에 따라 조작을 줄인 주행 화면으로 전환 |
| 4, 8초 | 7 | ‘신호 대기 · D’와 정지 안내, 주차 조작 없음 | 정지 중이어도 D이면 주행 화면 유지 |
| 5, 20초 | 3 | 주행 가능 거리 49 km, 연료 부족 안내 | 차량 상태를 이해하기 쉬운 말로 전달 |
| 6, 25초 | 4 → 49→620 km와 회복 확인 → ‘내 방으로’ 클릭 | 회복 화면에서 방으로 복귀 | 모의 주유 전후 거리 변화로 회복 시연 |
| 7, 25초 | 5 → 300 km 성장 안내 → ‘함께하기’ 클릭 → 성장 기록 → 내 방 | 어린이 성장 단계와 기록 표시 | 누적 동행을 성장으로 표현. 시간 경과를 압축한 모의 장면 |
| 8, 20초 | 0 → 거리 32 km·41분 요약 → ‘확인’ 클릭 | 요약 이후 방으로 복귀 | 하루의 동행을 마무리하는 기록 |
| 마무리, 10초 | 내 방 유지 | 마이카펫 이름과 토토 | 차량 상태를 친근하게 이해하고, 함께한 거리를 추억으로 남깁니다 |

각 버튼 클릭 후 2~3초 화면을 유지합니다. 위 시간은 설명을 포함한 권장 길이입니다.

## 선택 장면과 정확한 설명
- 꾸미기: 내 방의 옷장 열기 → 소품 선택 → ‘선택 저장’ → 내 방. 선택 상태만 저장되며 착용 그림 합성은 준비 중입니다. 실제 옷이 바뀐다고 설명하지 않습니다. 본편에서는 생략하거나 10초 내로 짧게 소개합니다.
- 빗길·위험 경고: 본편 종료 후 별도 부록으로 촬영합니다. M → 해당 미리보기 클릭. 미리보기는 샘플 상태로 바뀌므로 본편 중간에 섞지 않습니다.
- 실제 SDK 증거: 이 브라우저 영상과 분리합니다. 에뮬레이터의 실제 SDK 패널을 별도로 제시하며, 반복 알림과 실제 값 변경 검증을 구분합니다.
- 종료 후 M → ‘내 토토로 돌아가기’ → 닫기. 시연 전 저장 상태로 복귀합니다.

## 방해물 처리
- record=1에서 SDK 진단 패널·빌드 정보·시연 설정 버튼을 숨깁니다. 모의 데이터 표시는 항상 남깁니다.
- M으로 패널을 열고 닫습니다. 패널이 열려 있는 장면은 본편에 넣지 않습니다. 장면 선택 시 자동으로 닫힙니다. 닫기 버튼과 Escape도 있습니다.
- F는 전체 문서를 전체 화면으로 표시합니다. 전체 화면 중에는 전체 화면 버튼을 숨깁니다.
- 숫자 단축키는 입력창·한글 조합 중·길게 누름·Ctrl/Cmd/Alt/Shift 조합에서는 작동하지 않습니다.
- 자동 재생은 사용하지 않습니다. 6.5초 간격이 설명과 버튼 클릭 시간을 자를 수 있기 때문입니다.
- 도구/확장 프로그램 말풍선, 알림, 마우스 커서가 제목·토토 얼굴·숫자를 덮지 않는지 사용자 기기에서 확인합니다.

## 검증의 한계
실제 HMI 이벤트 처리 코드로 위 1→2→7→3→4→5→0 경로와 확인 버튼·저장 격리를 검증했습니다. 이는 실제 크롬의 픽셀 배치·키보드·전체 화면 권한·녹화 결과 검증을 대신하지 않습니다. 연결된 사용자 크롬 제어 도구가 없어 최종 화면은 사용자 기기에서 확인해야 합니다.
