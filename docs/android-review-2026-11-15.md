# Pleos 실행 후 점검 — 2026-11-15

## 확인된 사실
사용자 Mac에서 Gradle BUILD SUCCESSFUL, adb install Success, MainActivity 실행 및 실제 붕붕이 화면 표시 확인. 따라서 이전 체크리스트의 APK 빌드·설치·에뮬레이터 화면 실행은 완료로 갱신한다. 차량 SDK 연결, 실제 차량 검증과는 별개다.

## 이번 수정
- Android 쿼리에서는 웹 시연용 베젤·차량 패널·가짜 지도·상태바·공조 바 제거. Pleos가 할당한 창만 사용한다.
- 고정 1.88 화면비 제거, 창 높이를 채우며 작은 창에서 스크롤과 단일 열 배치 허용.
- 앱 내부에 모의 데이터 표시와 시연 설정 버튼 유지. 기존 웹 시연 모드는 유지.
- 반복 소품 SVG의 중복 clipPath ID를 고유 ID로 교체. 잘림 영역이 다른 인스턴스를 참조하는 결함 방지.
- 주행 가능 거리 설명에서 실제 연동처럼 읽히는 문구 정정.
- PR1의 저장 격리, 성장 보류, 터치 취소 개선 포함.

## 검증과 한계
Node 테스트 7개 스크립트 통과. Android assets 동기화 성공. 수정본 APK 빌드와 Mac WebView 시각 검수는 아직 수행하지 않았다. 최초 사용자 스크린샷의 실행 성공은 수정 이전 APK에 대한 증거다.

## 남은 P0
- 실제 Vehicle/CarUxRestrictions 연결 및 권한·미수신·유효기간 검증. 현재 공급기는 모의 값이다.
- 방 이미지에 캐릭터가 합쳐져 있어 성장 단계/소품과 실제 그림이 불일치한다. 빈 방과 단계별 투명 캐릭터 소스가 필요하다. 현재 미리보기는 리깅 모델이 아니다.
- 주유 감지는 주행 가능 거리 증가 추정이다. 실제 연료 신호/오탐 방지 필요.
- 경고 우선순위, 경고 중 거리 보류, 최초 ODO·차량별 저장, 실제 시동 종료 요약 미완료.
- 내비 목적지/경유지 연동 및 시스템 분할 창 전환 미검증.
- 배지 time/mileage, 성장 앨범, 이름 입력/부화, 방 꾸미기 미완료. 탭 존재는 기능 완료가 아니다.
- 성장 단계·거리·명칭은 최종 제출 문서로 합의해야 한다.

## 수정본 인수 테스트
1. 앱 안에 차량/공조/시스템 바가 중복되지 않는지 확인.
2. 모의 데이터 표시와 시연 설정 버튼이 모든 앱 화면에 남는지 확인.
3. 내 방·성장·배지·옷장·회복·요약 각각에서 잘림/중첩 확인.
4. S1–S5 실행 후 회복과 성장 이벤트 확인.
5. D/R/N 및 제한/미수신에서 상호작용 차단과 성장 보류 확인.
6. 시연 종료 후 기존 저장 상태 복원, 앱 재실행 후 유지 확인.
7. 작은 분할 창에서 버튼 접근·스크롤 확인.

## 버튼 응답 개선 후속 수정
옷장 소품 선택은 전체 화면/그리드를 다시 생성하지 않고 미리보기·선택 표시만 갱신한다. 적용 시에도 화면을 유지한다. 동일 탭/항목 재선택은 작업을 생략하고 변경 없는 저장 상태는 다시 기록하지 않는다. Android의 그림자·혼합·성장 애니메이션 비용을 줄였다. 8개 Node 테스트와 Android 자산 동기화를 통과했다. Mac 실제 응답 시간 측정은 아직 하지 않았으며, 에뮬레이터 전체의 지연 해결을 보장하지 않는다.

최신 main에는 팀원 변경이 있어 이 브랜치와 병합 충돌을 별도로 해결해야 한다. 이 수정은 feat/team1-demo-session에만 반영하며 main을 덮어쓰지 않는다.
