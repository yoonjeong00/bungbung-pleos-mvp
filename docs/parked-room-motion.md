# 토토 주차 모션 브라우저 미리보기

1. 저장소 루트에서 `python3 -m http.server --bind 127.0.0.1 8080 --directory dist` 실행.
2. 브라우저에서 `http://127.0.0.1:8080/?blink-preview=1` 열기.
3. 모의 데이터 패널에서 **내 방** 미리보기 선택. P·시동 ON·주행 제한 없음·심각한 경고 없음 상태에서만 움직인다. 신호 유효시간은 15초이며 내 방을 다시 선택하면 새 모의 신호로 재생할 수 있다.

방 배경은 고정하고 토토만 좌우로 살짝 흔들린다. 눈 감으며 웃는 표정과 짧은 터치 하트·끄덕임을 포함한다. 손 흔들기 없음. 감속·정지 여부와 관계없이 D, 주행 제한, 빨간 경고, 탭 숨김, 모션 줄이기 설정, 신호 만료에서는 모션이 중단된다. 일반 웹, Android/embedded, 녹화 모드, 실차 SDK 동작에는 적용되지 않는다. Android 빌드나 에셋 동기화는 이 변경에서 실행하지 않았다.

검증: `node --test tests/*.mjs`
